สร้างหน้า HTML เดียวสำหรับ dashboard งานทีมสมมติชื่อ “Lantern” ตามแบบที่กำหนดนี้:
- มีหัวหน้าเว็บ ชื่อทีม และวันที่ตัวอย่าง 5 ตุลาคม 2026
- มีตัวเลขสรุป 3 ช่อง: งานทั้งหมด 24, เสร็จแล้ว 16, รอดำเนินการ 8
- มีตารางงานตัวอย่าง 5 แถว พร้อมชื่อผู้รับผิดชอบ สถานะ และกำหนดส่ง
- มีช่องค้นหาและตัวกรองสถานะที่ทำงานด้วย JavaScript ในหน้า
- ใช้ CSS ในไฟล์เดียว รองรับมือถือ สีอ่านง่าย และ label สำหรับช่องกรอก
- ไม่ใช้ CDN, รูปภาพภายนอก, API, ไลบรารี, การ deploy หรือข้อมูลจริง

แบบและขอบเขตนี้อนุมัติแล้ว ให้สร้างให้เสร็จในคำตอบเดียว ไม่ถามเพิ่มเติม ไม่เรียก tools ไม่อ่านไฟล์ ไม่อ้างอิงสกิลอื่น และไม่เขียนคำอธิบาย ตอบเฉพาะ HTML ตั้งแต่ <!doctype html> ถึง </html> ไม่ครอบด้วย Markdown code fence
